# 🚜 Agri-Accountant (Farming Expense Manager)

## Introduction
This is a specialized **Financial Management Application** designed to help farm owners and partners track operational costs and automate profit-sharing. It eliminates manual paperwork by providing a digital ledger for seeds, labor, and other farming expenses.

---

## Features

### 👤 User Features
* **Authentication:** Signup, signin, and secure logout.

### 💰 Expense Management
* **Add Expense:** Category-wise expense logging (Seeds, Fertilizer, Labor).
* **Automatic Split:** Logic to divide costs based on partnership ratios.
* **Settlement:** View to see who owes how much to whom.

---

## API Documentation

The API is designed with REST principles and can be tested using Postman.
